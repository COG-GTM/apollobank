# apollobank 🚀

A fullstack GraphQL banking application built using React, Node & TypeScript.

## What's included?

- Login/register
- Dashboard
- Accounts
- Transactions
- Credit cards
- Settings
- Spending for this month chart
- Dummy data generator using faker

![dashboard](images/dashboard.png)

## Architecture

See [`docs/architecture.md`](docs/architecture.md) for how the client, server and database fit together, with a diagram ([`docs/diagrams/architecture.png`](docs/diagrams/architecture.png), source in [`docs/diagrams/architecture.dot`](docs/diagrams/architecture.dot)).

## Project layout

| Path | What it is |
|---|---|
| `client/` | React 17 app (Create React App 4), served on `:3000` |
| `server/` | Express + Apollo Server + TypeGraphQL API on `:4000`, TypeORM entities and the seed script |
| `docs/` | Architecture doc and diagram |
| `images/` | README screenshot |
| `package.json` | Root runner: starts server and client together with `concurrently` |
| `client/build/`, `server/dist/`, `node_modules/` | Build output and root dependencies that are committed to the repo; `server/dist/` is out of date, so rebuild with `npm run build` in `server/` before using it |

## Running the app

A root `package.json` provides a single command to start both the server (`:4000`) and client (`:3000`) together with prefixed, color-coded logs.

Before the first run you need PostgreSQL with the `expressbank` database and a `server/.env` with `ACCESS_TOKEN_SECRET` and `REFRESH_TOKEN_SECRET`; [`SETUP.md`](./SETUP.md) has the steps. Use Node 16 (Node 14 also works). With the committed lockfile, the client's `react-scripts@4` stops with `ERR_PACKAGE_PATH_NOT_EXPORTED` (from `postcss-safe-parser`) on Node 18 and newer.

First-time setup (installs root, server, and client deps):

```bash
npm install
npm run install:all
```

Then start everything:

```bash
npm start        # alias for `npm run dev`
```

`npm start` sets `NODE_OPTIONS=--openssl-legacy-provider` for the client, which Node 16 refuses (`not allowed in NODE_OPTIONS`). On Node 16, start the server and client in two terminals instead (see the cheat-sheet in [`SETUP.md`](./SETUP.md)).

Other scripts:

- `npm run dev` — same as `npm start`.
- `npm run seed` — seed the database (see below).
- `npm run install:all` — install dependencies in `server/` and `client/`.

For full prerequisites (Node, PostgreSQL, env vars), see [`SETUP.md`](./SETUP.md).

## Seeding the database

A seed script is provided to populate the database with example data for development.

Prerequisites: PostgreSQL running locally with the credentials defined in `server/ormconfig.json` (database `expressbank`).

From the repo root (or `npm run seed` inside `server/`):

```bash
npm run seed
```

This will:

- Truncate the `users`, `accounts`, `cards`, and `transactions` tables.
- Create a demo user plus 5 randomly generated users (each with 2 accounts, 2 cards, and 10 transactions per account).

Demo login credentials:

- **Email:** `demo@apollobank.com`
- **Password:** `password123`

All generated users share the password `password123`.
